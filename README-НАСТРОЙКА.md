# SwimWithSmile — Cloudflare (безплатно, бързо, без Google Sheet) 🚀

## 🆕 Версия 5 (ноември 2026) — истинска база на Cloudflare

Google Sheet + Apps Script отпаднаха. Сега всичко е на **Cloudflare, безплатно и без карта**:
- **Cloudflare Pages** — сайтът (неограничен трафик, сървъри и в София)
- **Pages Function** `functions/exec.js` — бекендът (същата логика като преди, пренесена от `Code.gs`)
- **D1** — SQLite базата (5 GB безплатно)

Заявка отнема десетки милисекунди вместо 1,5–4 секунди. Паролите, токените и родителските кодове остават същите — никой не трябва да влиза наново.

### Пускане (веднъж, ~15 минути)
1. **Качи кода в GitHub** (репото `SwimWithSmile_Project`).
2. <https://dash.cloudflare.com> → регистрация (безплатно, без карта).
3. **Storage & Databases → D1 SQL Database → Create** → име `sws` → Create. (Таблиците се създават сами.)
4. **Workers & Pages → Create → Pages → Connect to Git** → репото → Framework preset **None**, Build command *(празно)*, Build output directory **/** → **Save and Deploy**. Проектът да се казва **swimwithsmile** → адресът е `https://swimwithsmile.pages.dev`. (Ако името е заето — смени `PROD_ORIGIN` в `js/api.js`.)
5. В проекта: **Settings → Bindings → Add → D1 database** → Variable name **`DB`** → база **`sws`** → Save. После **Deployments → … → Retry deployment** (за да вземе базата).
6. Отвори `https://swimwithsmile.pages.dev/exec` — трябва да пише „SwimWithSmile API е активно."
7. **Пренос на данните:** в Google таблицата постави новия `apps-script/Code.gs` в Apps Script → Save → презареди таблицата → меню **SwimWithSmile → ☁️ Премести данните в Cloudflare** → въведи `https://swimwithsmile.pages.dev` → Allow. Пренася всичко заедно с ключа на паролите. Работи само докато новата база е празна.
8. Готово — влез на новия адрес със същия имейл и парола.

### Google Calendar (вече без споделяне)
Всеки треньор: Профил → Google Calendar → „Календарът → сайта" → поставя **„Таен адрес във формат iCal"** (Google Calendar → ⋮ до календара → Настройки и споделяне → Интегриране на календара). Сайтът го проверява на 10 мин, ↻ в графика — веднага. Филтърът е същият: само имена на плувци, почивки/отпуск/болничен и `#sws`; `#лично` скрива.

### Имейли (по желание)
Settings → Variables and Secrets: `BREVO_KEY`, `BREVO_SENDER` (и по желание `APP_URL`). Имейлите тръгват веднага след записа. Сутрешният дайджест засега не е включен.

### Разработка
- Локално: `npx wrangler pages dev . --d1 DB=sws-local` → <http://127.0.0.1:8788>. (С Live Server сайтът ползва онлайн версията.)
- Бизнес логиката е в `apps-script/Code.gs` + `tools/overrides.js` (замества услугите на Google). След промяна: `node tools/build-core.mjs` → обновява `functions/_lib/core.js`.

## Версия 4 (ноември 2026) — бързо, безплатно, общ календар

**Какво е новото**
- **Скорост.** Бекендът пази таблиците в кеша на Google (CacheService) — четенето вече не отваря Google Sheet всеки път. Сайтът пази всеки отворен екран и го показва веднага при следващо отваряне, а свежите данни идват във фона. Графикът зарежда месеца с една заявка вместо две и подготвя съседните месеци. На всеки 10 мин тригер `warmUp` държи кеша пълен.
- **Google Calendar на двамата.** Твоят календар се чете автоматично; колегата споделя своя с твоя имейл и включва „Моят календар" в сайта (Профил → Google Calendar → „Календарът → сайта"). В сайта излизат **само**: събития с име на плувец, почивка/отпуск/болничен (🌴) и събития с ключова дума на отбора (по подразбиране `#sws`). Всичко друго („Гироси", „Басейн вечерта") е скрито. `#лично` в заглавието скрива всичко.
- **Без ценоразпис.** Всичко е безплатно, без лимити на треньори и плувци.
- **Няколко отбора.** Един треньор = един имейл, но може да е в колкото отбора иска. Бутонът с името на отбора горе сменя отбора. Покана към човек с профил → влиза със същата парола и отборът се добавя.
- **Метри.** Дължина на басейна (Отбор → Басейн, напр. 17 м; може и за отделна тренировка). В тренировката ✎ до името → „4x6, 5x8" → 64 дължини × 17 м = 1 088 м. Бутон „🏊 Метри" — едни и същи серии за всички. „4x50м" се брои направо в метри. Метрите се виждат в картона, историята и при родителя.

### Обновяване от версия 3 (веднъж, ~5 минути)
1. Копирай **целия** нов `apps-script/Code.gs` в Apps Script → 💾 Save.
2. В Google таблицата: меню **SwimWithSmile → 1) Първоначална настройка** → Google ще поиска нови разрешения (кеш, тригери) → **Allow**. Това добавя новите колони и тригерите `warmUp` + `onSheetChange_`. Данните не се пипат.
3. **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** (адресът остава същият).
4. Качи сайта (виж „Хостинг" долу).
5. За колегата: тя отваря calendar.google.com → до нейния календар **⋮ → Настройки и споделяне → Споделяне с конкретни хора → твоя имейл → „Преглед на всички подробности за събитията"**. После в сайта: Профил → Google Calendar → включва „Моят календар".

Ако редактираш таблицата на ръка и сайтът не го вижда веднага — меню **SwimWithSmile → Изчисти кеша на сайта**.

### Хостинг (безплатно) — Cloudflare Pages
Сайтът е статичен (HTML/CSS/JS), а „сървърът" е Apps Script — значи хостингът трябва само да сервира файлове. Най-бързият безплатен вариант е **Cloudflare Pages**: неограничен трафик, сървъри и в София, без карта, адрес `swimwithsmile.pages.dev`.
1. <https://dash.cloudflare.com> → регистрация (безплатно).
2. **Workers & Pages → Create → Pages → Connect to Git** → избери репото `SwimWithSmile_Project`.
3. Framework preset: **None** · Build command: *(празно)* · Build output directory: **/** → **Save and Deploy**.
4. Всеки `git push` в `main` качва нова версия сама. Файлът `_headers` казва колко да се кешира.

Netlify също става, но новите безплатни акаунти имат 300 кредита/месец (≈20 качвания) и при изчерпване сайтът спира до края на месеца.

## 🆕 Версия 3 (октомври 2026) — какво е новото

**За треньора**
- **„Днес"** — началният екран след вход: днешните тренировки с ✓/✗ до всяко дете (записва се веднага), „Всички са тук", сигнали (поредни отсъствия, изтичащо медицинско, липсващ телефон, рождени дни) и следващите 7 дни.
- **Групи** (Клуб → Групи) — „Делфини" пн и ср в 17:00. Тренировка за групата → децата се добавят сами.
- **Повтарящи се тренировки** — „Повтаряй всяка седмица" + дни + до дата. Промяна/изтриване „и на следващите от серията". Отмяна на тренировка (не се брои в посещаемостта).
- **Картон** — родител, телефон (обаждане с едно докосване), имейл, спешен контакт, ⚠ предупреждение (вижда се на всяка тренировка), СОП, алергии, медицинско до, съгласие за данните (GDPR), архивиране, печат.
- **Умения и нива** — стълба от 17 умения в 4 етапа („Издишва под водата", „Плува без коланче", „Без плавници"…). Точки: +10 за идване, +30–60 за умение, +25 за награда, +20 за състезание (+бонус за медал). Нива: Капка → Жабче → Рибка → Октопод → Костенурка → Делфин → Акула → Кит.
- **Състезания** — дисциплина, време, място, град; личният рекорд се отбелязва сам.
- **Награди за много деца наведнъж**, **Посещаемост** (месечна таблица по групи), бележка за родителя към всяка тренировка.
- **Google Calendar** — График → Google Calendar → „Добави". Целият отбор или само твоите тренировки; обновява се само.

**За родителя** — ниво и точки, умения, награди, състезания, бележки от треньора, следващи тренировки, посещения. „Запомни ме" — не въвежда кода всеки път. Здравни данни и вътрешни бележки НЕ се виждат.

**Скорост** — данните за децата/групите се пазят в браузъра и се показват веднага; service worker кешира сайта → второто отваряне е моментално.

### Обновяване от версия 2 (веднъж, ~3 минути)
1. Копирай **целия** нов `apps-script/Code.gs` в Apps Script → 💾 Save.
2. **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** (адресът остава същият). Ако Google поиска нови разрешения (за имейли) — Allow.
3. Качи сайта в Netlify (git push или плъзгане на папката).
4. Готово. При първата заявка скриптът сам добавя новите табове (`Groups`, `Skills`, `ChildSkills`, `Outbox`) и колони **накрая** — старите данни не се местят.

### Известия по имейл (Brevo, безплатно до 300/ден)
1. Регистрация в <https://www.brevo.com> → **Senders** → добави и потвърди имейла, от който ще пращаш.
2. **SMTP & API → API Keys → Generate a new API key** → копирай (`xkeysib-…`).
3. В Google таблицата: меню **SwimWithSmile → 3) Известия по имейл (Brevo)** → постави ключа, имейла и адреса на сайта.
4. Провери с **„Тестов имейл до мен"**.

Какво се праща: на родителя — при награда, ново умение, състезание, нова карта за напредък и седмично обобщение в неделя (ако в картона има имейл и е включено). На треньорите — сутрин в 7:00, само ако има нещо ново (2+ поредни отсъствия, медицинско изтича след 14 дни, рожден ден). Бутонът „Изпрати на …" в картона праща кода за достъп на родителя.

## 🆕 Отбори, регистрация и покани (версия 2)

Сайтът вече е платформа: всеки може да се регистрира, да създаде **отбор** и да покани колега с линк.
Всеки отбор вижда **само своите** деца, тренировки и постижения.

**Обновяване от старата версия (веднъж):**
1. Копирай новия `apps-script/Code.gs` в Apps Script → 💾 Save.
2. **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** (адресът остава същият).
3. Готово. При първата заявка скриптът сам добавя нов таб `Teams` и колони `teamId`/`role` **накрая** на табовете
   (старите колони не се местят) и прехвърля всички съществуващи треньори и данни в отбор „SwimWithSmile“.
   Първият треньор в таб `Coaches` става **собственик** — той кани и сменя плана.

**Планове** (в `Code.gs` → `PLANS`, цените са в `js/landing.js` → `PLANS`):
Соло — 1 треньор / 15 деца · Отбор — 3 треньори / 60 деца · Клуб — 10 треньори / 300 деца.
Плащанията **още не са свързани** — собственикът сменя плана от страница „Отбор“ без заплащане.

**Google Calendar** се показва само на първоначалния отбор (това е твоят личен календар) — новите отбори не го виждат.

## Стъпка 1 — Направи Google таблицата и бекенда

1. Отиди на <https://sheets.google.com> и създай **нова празна таблица**. Наречи я напр. „SwimWithSmile DB".
2. От менюто горе: **Разширения → Apps Script** (Extensions → Apps Script).
3. Изтрий примерния код, отвори файла **`apps-script/Code.gs`** от тази папка, копирай **цялото** му съдържание и го постави в редактора.
4. Натисни 💾 **Save** (иконата за запис).
5. Обнови (F5) прозореца на таблицата — горе ще се появи ново меню **„SwimWithSmile"**.
6. Меню **SwimWithSmile → „1) Първоначална настройка"**. Google ще поиска разрешение — избери акаунта си, „Advanced → Go to project → Allow". Това създава всички табове (Coaches, Children, Sessions…).

## Стъпка 2 — Направи си треньорски профил

1. В таблицата отвори таб **`Coaches`**. Вече има един ред с `coach@example.com`.
2. Смени **email** с твоя имейл и в колона **passwordHash** напиши паролата, която искаш (засега в чист вид).
   - За втори треньор — добави нов ред: `id` остави празно (не е нужно), `fullName`, `email`, `passwordHash`, а в `active` напиши `TRUE`.
   - ⚠️ Ако добавиш ред ръчно без `id`, по-добре сложи някакъв уникален текст в `id` (напр. `coach-2`).
3. Меню **SwimWithSmile → „2) Хеширай паролите"**. Паролите се превръщат в защитен вид (`sha256:…`). Готово — вече не се пазят в четим вид.

## Стъпка 3 — Публикувай бекенда (вземи адрес)

1. В Apps Script редактора горе вдясно: **Deploy → New deployment**.
2. При „Select type" (зъбчатото колело) избери **Web app**.
3. Настрой:
   - **Execute as:** `Me` (твоят акаунт)
   - **Who has access:** `Anyone`
4. **Deploy** → разреши достъпа. Копирай показания **Web app URL** — завършва на **`/exec`**.
   Пример: `https://script.google.com/macros/s/AKfy.../exec`

> Всеки път, когато промениш `Code.gs`, прави **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**, за да влезе в сила. Адресът остава същият.

## Стъпка 4 — Свържи сайта с бекенда

Отвори **`js/api.js`** и на ред 12 замени:

```js
const DEFAULT_BASE = 'ПОСТАВИ_ТУК_ADRESA_KAM_APPS_SCRIPT';
```

с твоя `/exec` адрес, напр.:

```js
const DEFAULT_BASE = 'https://script.google.com/macros/s/AKfy.../exec';
```

Запиши файла.

> Алтернатива: може и да не пипаш кода — при първо отваряне на сайта натисни ⚙️ (горе вдясно на екрана за вход) и постави адреса там. Но тогава всеки браузър (и на родителите) трябва да го въведе, затова е по-добре да го сложиш направо в кода.

## Стъпка 5 — Пусни сайта на Netlify (безплатно)

**Най-лесно (без Git):**
1. Влез в <https://app.netlify.com> → **Add new site → Deploy manually**.
2. Плъзни **цялата тази папка** в прозореца. Сайтът тръгва за секунди на адрес тип `нещо.netlify.app`.
3. Всяко следващо обновяване — пак плъзни папката (или използвай Git по-долу).

**По-добре (с Git, автоматично при промяна):**
1. Качи папката в GitHub хранилище.
2. В Netlify: **Add new site → Import from Git** → избери хранилището. Build command: празно. Publish directory: `.`
3. Всеки `git push` обновява сайта автоматично.

## Полезно да знаеш

- **Данните са в таблицата.** Можеш по всяко време да отвориш Google Sheet и да гледаш/поправяш на ръка. Внимавай само да не триеш заглавния (първи) ред.
- **Резервно копие:** Файл → Изтегли → Excel, когато искаш архив. Или „Копие" на таблицата.
- **Двама души едновременно:** предвидено е — при запис има кратко заключване, за да не се застъпват. При вашия обем е напълно спокойно.
- **Сигурност:** тайният ключ за паролите/входа стои в Google (Script Properties), не в сайта. В браузъра няма нищо, с което чужд човек да пише в базата.
- **Ново поле искаш?** Кажи ми — добавя се колона в съответния таб + два-три реда код.

Ако нещо не тръгне (напр. „Няма връзка със сървъра"): провери, че адресът в `api.js` завършва на `/exec` и че при Deploy си избрал **Who has access: Anyone**.

## Google Calendar → сайта

Събитията от **основния ти Google календар** се показват в екрана „График" заедно с тренировките, но с **лилав пунктир и 📅** — само за преглед (не се редактират от сайта). Едно събитие се показва на деня, в който започва.

Понеже това добавя достъп до Календара, трябва **веднъж да преразрешиш скрипта**:

1. Обнови `Code.gs` в Apps Script с новата версия (копирай наново целия файл).
2. 💾 Save.
3. **Deploy → Manage deployments → ✏️ (Edit) → Version: New version → Deploy**.
4. Google ще поиска ново разрешение — този път и за **Календар**. Потвърди (Allow). Адресът остава същият.

Това е всичко. Отвори „График" — събитията от календара ще се появят. Ако още не си разрешил Календара, сайтът просто няма да показва събития (тренировките пак си работят).

> Бележка: показва се основният ти календар — ако държиш там и лични събития, ще се виждат и те. Ако предпочиташ отделен календар само за школата, кажи ми — сменяме един ред и слагаме конкретния календар.
